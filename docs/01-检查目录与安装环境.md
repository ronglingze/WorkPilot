# 01｜检查目录与安装环境（预计 15～30 分钟）

全部命令都在 **WorkPilot 根目录** 执行；不要先 `cd agentscope-source`。

## 1. 确认 Python

Windows PowerShell：

~~~powershell
py -3.11 --version
~~~

macOS / Linux：

~~~bash
python3 --version
~~~

**要求 Python ≥ 3.11**。如果 Windows 未安装 3.11 而已有 3.12/3.13，可先执行 `python --version`，确认满足要求，再用 `python` 替换后面 `py -3.11`。

如果 Python 不符合要求，先安装 Python 3.11+，不要继续安装依赖。

## 2. 创建虚拟环境

Windows PowerShell（有 `py -3.11` 时）：

~~~powershell
py -3.11 -m venv .venv
~~~

macOS / Linux：

~~~bash
python3 -m venv .venv
~~~

期望：WorkPilot 下生成 `.venv/` 目录。这个目录已被 `.gitignore` 排除。

## 3. 激活环境

Windows PowerShell：

~~~powershell
.\.venv\Scripts\Activate.ps1
~~~

macOS / Linux：

~~~bash
source .venv/bin/activate
~~~

期望：终端前面显示 `(.venv)`。

如果 PowerShell 禁止运行脚本，**不用修改系统安全策略也可以继续**：直接用 `.\.venv\Scripts\python.exe -m pip ...` 替代下文的 `python -m pip ...`，运行脚本也使用 `.\.venv\Scripts\python.exe`。

## 4. 升级 pip

~~~bash
python -m pip install --upgrade pip
~~~

## 5. 检查本地 AgentScope 源码位置

Windows：

~~~powershell
Test-Path .\agentscope-source\pyproject.toml
~~~

macOS / Linux：

~~~bash
test -f ./agentscope-source/pyproject.toml && echo found
~~~

期望：Windows 显示 `True`，macOS / Linux 显示 `found`。

没有的话：说明源码目录不在预期位置。先执行 `dir`（Windows）或 `ls`（macOS/Linux）并确认位置；如果源码在别处，先把下面安装命令中的路径换成实际位置，不要重复克隆。

## 6. 从本地源码安装 AgentScope

~~~bash
python -m pip install -e ./agentscope-source
~~~

`-e` 表示可编辑安装：以后你阅读或调试本地源码，不需要把源码复制到自己的 `examples/`。

依赖安装可能花几分钟，网络较慢时不要连续反复执行。

## 7. 验证安装

~~~bash
python -c "import agentscope; print(agentscope.__file__)"
~~~

期望：打印本地 AgentScope 的安装路径，最好位于 `WorkPilot/agentscope-source/src/agentscope/`。

如果路径指向系统 Python 而不是 `.venv`，先检查环境是否激活。
