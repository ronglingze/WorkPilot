# 01｜检查目录与安装环境（预计 15～30 分钟）

全部命令都在 **WorkPilot 根目录** 执行；不要先 `cd agentscope-source`。本指南使用 Conda 环境，不需要在项目目录创建 `.venv/`。

## 1. 激活 Conda 环境并确认 Python

先查看已有环境：

~~~bash
conda env list
~~~

如果目标环境尚未激活，用环境名激活（将 `<环境名>` 替换为实际名称）：

~~~bash
conda activate <环境名>
~~~

如果终端前面已经显示当前 Conda 环境名，则可直接继续。检查 Python 版本和解释器位置：

~~~bash
python --version
python -c "import sys; print(sys.executable)"
~~~

**要求 Python ≥ 3.11**。确认 `python` 来自你要使用的 Conda 环境；若版本不符合要求，先切换到合适的 Conda 环境，不要继续安装依赖。

## 2. 确认 Conda 环境已激活

~~~bash
conda info --envs
~~~

期望：当前环境前有 `*`，终端提示符也显示该环境名。后续的 `python -m pip` 和 `python` 命令都会使用这个环境中的解释器。

## 3. 升级 pip

~~~bash
python -m pip install --upgrade pip
~~~

## 4. 检查本地 AgentScope 源码位置

Windows：

~~~powershell
Test-Path .\agentscope-source\pyproject.toml
~~~

macOS / Linux：

~~~bash
test -f ./agentscope-source/pyproject.toml && echo found
~~~

期望：Windows 显示 `True`，macOS / Linux 显示 `found`。

没有的话：说明源码目录不在预期位置。先执行 `dir`（Windows）或 `ls`（macOS/Linux）并确认位置；如果源码在别处，先把下面安装命令中的路径换成实际位置，不要重复克隆。

## 5. 从本地源码安装 AgentScope

~~~bash
python -m pip install -e ./agentscope-source
~~~

`-e` 表示可编辑安装：以后你阅读或调试本地源码，不需要把源码复制到自己的 `examples/`。

依赖安装可能花几分钟，网络较慢时不要连续反复执行。

## 6. 验证安装

~~~bash
python -c "import agentscope; print(agentscope.__file__)"
~~~

期望：`agentscope` 指向 `WorkPilot/agentscope-source/src/agentscope/`；Python 解释器则位于当前 Conda 环境中，可用第 1 步的 `sys.executable` 输出确认。如果路径不符合预期，先确认 Conda 环境已激活，再用 `python -m pip` 重装。
