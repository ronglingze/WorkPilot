# 00｜先看这里：只做一小步

## 今天的目标

**不需要 GPU，不训练模型。** 先确认工作目录，安装 AgentScope，然后让 API 模型说出一句话。

当前唯一目标：成功执行 `python examples/01_chat.py`。

## 第 0 步：把 WorkPilot 项目用 VS Code 打开

1. 找到你电脑上的 `WorkPilot` 文件夹。
2. VS Code 选择「文件 → 打开文件夹」，选中 `WorkPilot`。
3. 打开「终端 → 新建终端」。
4. 执行：

~~~bash
git status
~~~

期望看到你在 `main` 分支。如果提示 `not a git repository`，说明终端没进入项目目录。

## 第 1 步：拉取刚添加的学习文件

~~~bash
git pull --ff-only
~~~

成功后，你应看到 `README.md`、`docs/`、`examples/`、`data/`。

如提示 `local changes would be overwritten`：**先停下，不要运行 reset/clean，不要删除本地文件。**

## 第 2 步：确认 AgentScope 源码确实在本地

项目目录应该像这样：

~~~text
WorkPilot/
├── agentscope-source/    ← 你克隆的 AgentScope 官方源码
│   ├── pyproject.toml
│   ├── examples/
│   └── src/agentscope/
├── docs/
├── examples/
├── data/
├── README.md
└── .gitignore
~~~

若你的源码文件夹叫 `agentscope` 或者在 WorkPilot 以外，暂时不要移动它；在下一份文档找对应说明。
