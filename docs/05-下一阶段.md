# 05｜完成第一个 Agent 之后做什么？

**这不是本周任务**，只是告诉你未来改 Harness 的方向。

## 第一阶段（现在）

- API 模型调用；
- 认识 Agent Loop；
- 自定义一个只读 Tool；
- 学会定位框架源码。

## 第二阶段（之后一起实现）

1. **Trace Recorder**：记录模型调用、工具调用、执行耗时与结果；
2. **Task State**：明确一个长任务当前执行到哪里；
3. **Verifier**：使用确定性程序检查结果，而不是让模型自己说“我做对了”；
4. **Recovery**：工具失败之后允许安全重试或局部重规划。

## 第三阶段（评测稳定后）

- 自建可重置任务集；
- 对比 ReAct 与增强 Harness；
- 收集验证通过的执行轨迹；
- 做 3B/4B 模型的 QLoRA SFT（有条件再做 RL）。

**现在不要：** 一次性接入所有 MCP、部署向量数据库、上多 Agent、租显卡或自己重写 AgentScope Runtime。

你的第一条里程碑只有一句话：

> 我知道 AgentScope 如何把 LLM 返回的 Tool Call 变成 Python 函数执行，并能亲手跑通一次。
